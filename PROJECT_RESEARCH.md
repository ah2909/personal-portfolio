# Project presentation research

Only documentation, UI components, API source, and service implementation were used to describe the projects. Original project configuration, environment, lockfiles, keys, database volumes, and deployment files were excluded. No source project files were changed or copied into this portfolio.

## Cryptofolio

Reviewed frontend route structure, the public welcome page, portfolio and exchange API services, and feature-component organization. Reviewed backend `architecture.md`, `README.md`, API routes, the FastAPI analysis route, and the Binance WebSocket implementation.

Confirmed portfolio management, transaction sync and CSV import, market data, exchange connections, AI analysis and research, revocable sharing, and a separate alert service delivering Telegram notifications. The presentation makes no claim of investment performance, exchange interoperability testing, or a live connection from this portfolio.

## E-Commerce

Reviewed `FEATURES.md`, architecture documentation, storefront customization documentation, frontend checkout and appearance routes, and backend checkout and payment HTTP handlers.

Confirmed multi-store host routing, catalog and variants, inventory reservations, atomic idempotent checkout, order snapshots, guest/registered flows, appearance presets, Vietnamese addresses and VND amounts, workforce permissions, and VietQR manual reconciliation. Live MoMo and social login validation remains pending according to the feature inventory. Roadmap and deferred capabilities are not presented as completed.

## Visuals

The project previews are original illustrative interface compositions, not screenshots of production systems. Amounts, product names, orders, risk scores, and stock counts are sample data. Published demo and source URLs are left blank until the owner supplies them.
